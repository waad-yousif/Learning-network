# شبكة التعلم

## اليوم بحثت عن الشبكات وفهمت:

### 1 - السيرفر
هو الجهاز الكبير البخزن كل حاجة، مثلا لو عايزة افتح اليوتيوب، الفيديو موجود في سيرفر اليوتيوب.

### 2 - السويتش
كل الاجهزة بتتوصل فيهو وبكون فيهو فتحات كتيرة، وهو البخلي الاجهزة تتواصل مع بعض جوا مبنى واحد (شبكة داخلية).

### 3 - الراوتر
هو البخلي الاجهزة تتصل بشبكة خارج المبنى عبر الانترنت.
