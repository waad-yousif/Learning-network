# Learning-network

اليوم بحثت عن الشبكات و فهمت:

1) السيرفر
هو الجهاز الكبير البخزن كل حاجه مثلا لو عايزه افتح اليوتيوب الفيديو والصور موجوده في سيرفر اليوتيوب

2) السويتش
الاجهزه كلها بتتوصل فيهو وبكون فيهو فتحات كتيره عشان كل جهاز تتوصل حتى الراوتر بتوصل فيهو وهو البخلي الاجهزه تتواصل مع بعضها في مبنى واحد (شبكه داخليه)

3) الراوتر
وهي بخلي الاجهزه تتصل بشبكه خارج المبنى عبر الانترنت
